# View Lineage Graph

## Goal

Inspect lineage graph in UI to understand data flow.

## Steps

1. Open lineage page.
2. Filter by run or dataset.
3. Inspect node and edge details.

## Command

```bash
open http://localhost:3000/lineage
```

## Result

Graph displays dataset and task relationships with directional edges.
