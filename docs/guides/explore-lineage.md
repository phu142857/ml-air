# Explore Lineage in UI

## Goal

Explore dataset and task dependencies interactively in UI.

## Steps

1. Open lineage page.
2. Select a run or dataset.
3. Traverse upstream and downstream edges.

## Command

```bash
xdg-open http://localhost:3000/lineage
```

## Result

You can trace where a dataset came from and which tasks consumed it.
