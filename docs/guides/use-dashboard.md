# Use Dashboard

## Goal

Use the dashboard to inspect run throughput and recent failures.

## Steps

1. Open dashboard page.
2. Filter by project and time range.
3. Open failed runs for details.

## Command

```bash
xdg-open http://localhost:3000
```

## Result

You can quickly identify unhealthy pipelines and investigate impacted runs.
