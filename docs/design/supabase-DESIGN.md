## Overview

Professional yet approachable developer-focused design with a dark-first aesthetic. The interface feels technical but not intimidating, with generous whitespace and clear hierarchy that builds trust and credibility. The signature green accent adds energy without overwhelming the clean, minimal foundation.

Centered max-width containers with generous vertical spacing. Grid-based logo arrangements and consistent horizontal padding. Section spacing follows a clear rhythm with large gaps between major content blocks.

Uses a 4px base grid with scale: 1, 2, 3, 4, 5, 6, 8, 12, 16, 20, 24, 32.

## Typography
- **Headline Font**: Circular
- **Body Font**: Circular
- **Label Font**: Circular
- **Code Font**: Source Code Pro

Circular serves as the primary typeface across all text roles, creating visual consistency while relying on size and weight variations for hierarchy. The font maintains excellent readability at all sizes with generous line heights (1.5x ratio). Weight is used sparingly - primarily 400 with selective 500 for emphasis. Letter spacing is minimal except for the distinctive negative tracking on larger headings and expanded spacing on code elements.

## Elevation

Minimal shadow strategy with subtle elevation primarily achieved through color contrast and borders rather than dramatic shadows. The design embraces relative flatness with depth conveyed through layered backgrounds and subtle color variations.

## Do's and Don'ts
- Do use the signature green sparingly to maintain its impact and brand recognition
- Don't mix corner radius values - stick to the established 6px, 8px, 12px, 16px scale
- Do maintain generous line heights (1.5x minimum) for optimal code readability
- Don't use font weights heavier than 500 to preserve the clean, technical aesthetic
- Do ensure sufficient contrast ratios, especially in dark mode interfaces
- Don't overcrowd layouts - embrace whitespace as a design element
- Do use consistent spacing multiples of 4px for visual rhythm
- Don't introduce additional accent colors that compete with the brand green
